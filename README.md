# CAMPUS LINK

## Como abrir
1. Baixe o arquivo campus_link_prototipo.html.
2. Abra-o em um navegador atualizado (Chrome, Firefox, Edge etc.).
3. Não é necessário instalar nada nem ter internet: CSS, dados de exemplo e interações estão no próprio arquivo.

## Fluxos demonstrados
### ESTUDANTE
- Visão geral e oportunidades em destaque.
- Criar/editar informações acadêmicas e profissionais.
- Adicionar projetos, experiências e cursos.
- Controlar a visibilidade demonstrativa do perfil.
- Buscar/filtrar vagas e demonstrar interesse.
- Acompanhar candidaturas e consultar feedback demonstrativo.

### EMPRESA
- Visão geral de recrutamento.
- Buscar estudantes por nome, curso e competências.
- Consultar perfis e simular contato profissional.
- Cadastrar vagas de estágio.
- Consultar candidaturas e atualizar status/feedback.

**Observação**: Este é um protótipo de interface para a atividade acadêmica, não uma aplicação de produção. Os nomes, perfis, empresas, vagas e candidaturas são dados fictícios. As alterações são armazenadas apenas na memória da página e são perdidas ao recarregar. Autenticação, banco de dados, envio real de mensagens, publicação pública e controles efetivos de segurança/privacidade ainda precisariam ser desenvolvidos.
